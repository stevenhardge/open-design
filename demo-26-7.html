Line Level Doc Merge + Linking Dragonstone

Invoice Document Merging

Supporting documents — receipts, PO confirmations, subcontractor invoices — can now be attached at the line level on timesheets, purchase journals, disbursement journals, and expense reports, then merged into the final invoice PDF output in Web Reports.

  1. Open a Purchase Journal and attach a vendor receipt to a line item
  2. Navigate to PM Bill Review — show the doc merge preview on the invoice
  3. Generate the invoice PDF in Web Reports — merged document appears inline
  4. Show the same flow for a Disbursement Journal with a subcontractor invoice attached
Talking points
  • Eliminates manual PDF assembly — clients were stitching invoices in Acrobat
  • Works across all four journal types: timesheets, PJ, DJ, expense reports
  • Preview available directly inside PM Bill Review before generating the final invoice
  • Generic dialog pattern reused for expense line item docs (consistent UX)

Rev Rec Formula Builder Seasmoke

Custom Percent Complete Formulas

The biggest single feature in 26.7. Users can now define custom percent-complete formulas for revenue recognition — with a full builder UI, variable glossary, async calculation engine, and integration into Bill Review and Project Data.

  1. Open the Formula Builder — show the list of existing formulas
  2. Create a new formula: pick variables from the Glossary tab, compose the expression
  3. Show the Info Detail panel — formula metadata and validation
  4. Assign the formula to a project via Project Data settings
  5. Run "Update Percent Complete" from Bill Review — show the progress indicator
  6. View the calculated results on the project
Talking points
  • Replaces rigid built-in formulas with user-defined calculations
  • Full CRUD: create, view, edit, delete formulas
  • Async calculation engine handles large project portfolios without blocking the UI
  • WBS-level metrics calculation — granular percent complete at the work breakdown level
  • Onboarding wizard guides new customers through base code configuration
  • Includes guard rails: duplicate request prevention, zero-cap handling, sub-contractor value corrections
